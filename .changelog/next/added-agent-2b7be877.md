- MiniMax H3 video generation now runs on Windows with an NVIDIA GPU, through diffusers' MiniMaxH3ModularPipeline. The macOS list has had H3 since #242, but it runs on PipeNetwork's Apple-Silicon MLX port, so an NVIDIA box had no H3 path at all — the Windows video catalog held exactly one model (LTX-Video 0.9.5). A new `minimax_h3_cuda` BYOV runtime (`~/.portos/minimax-h3-cuda`, installed from Video Gen or `INSTALL_MINIMAX_H3_CUDA=1 bash scripts/setup-image-video.sh`) plus a `MiniMax H3 CUDA int8` model entry bring the same joint video+audio model, the same 768px 32-aligned canvas, the same fl2va first/last keyframe anchoring and the same license gate to the Windows list. Weights are ~144 GB, rendering needs ~24 GB VRAM and a 96 GB-RAM host (~75 GB of the weights stay resident off-GPU for the whole render), and the runner picks its offload recipe from the card's own VRAM (bf16 auto-offload at 60 GB+, int8 + streamed block offload at 20 GB+, int8 + leaf-level below).
