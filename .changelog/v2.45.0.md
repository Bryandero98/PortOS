# Release v2.45.0

Released: 2026-08-16

## Highlights

- **Music Studio and remote audio.** Create richer instrumental tracks, hand work off to selected federation peers, and keep renders visible and controllable across restarts.
- **AI agent reliability.** Long-running local agents, OpenCode setup, Codex effort selection, and branch reconciliation now fail more clearly and recover more predictably.
- **Creative workflow upgrades.** Music commissions can use Digital Twin taste guidance, while Three.js previews add inspectable model audits and adaptive rendering.
- **Faster, more trustworthy automation.** CI and test runs avoid redundant work, and planning and claim workflows preserve their review, completion, and ownership guarantees.
- **Practice and story tools.** Morse training adapts to recurring confusion patterns, QUICK POST supports timed sessions, and story planning gains a dedicated climax role.
- **Privacy-conscious agent context.** An opt-in local MCP surface supplies bounded, read-only context with clear privacy controls.
- **System visibility.** The new System Resources dashboard brings storage, model-memory, cleanup, and active-job status into one place.

## Added

- Add copy buttons for agent IDs on active and historical agent cards
- Manual managed-app forge claims now pass the selected issue title and body directly into the agent prompt.
- App Issues claims now accept optional override context and instructions.

- Music generation now offers an instrumental-only option that leaves saved track lyrics intact.
- Music Designer now creates MiniMax-ready structured captions with tempo, meter, vocal, production, and section-by-section arrangement guidance.

- Add an authenticated federated audio provider API with conservative capacity admission and integrity-checked results (#4348).
- Instances can now opt into a peer's remote audio capacity and allowlist exact models, with stale or busy providers blocked before assignment (#4348).
- Music generation can now run privacy-safe structured instrumental profiles on an explicitly selected peer, survive consumer restarts, relay progress and cancellation, and import only integrity-verified audio (#4348).
- Planner-filed issues now get optional slashdo dispatch hints and contributor labels like good first issue when the work actually fits.
- Three.js model previews now offer shareable audit cameras and material inspection modes without changing the saved model.
- Adapt Three.js model previews to frame pressure with an inspectable fixed-quality override
- CoS agents now receive focused Three.js scene guidance alongside their task workflow.
- Added an opt-in, loopback-only MCP agent-context surface with bounded read-only tools, privacy profiles, and Settings controls (#4411).
- Agent context now includes a fixture-backed contract evaluator with machine-readable privacy, scope, freshness, and budget results.
- Morse practice now adapts to recurring character confusions and progresses into words, callsigns, and short QSO phrases.
- Added a distinct climax arc role across story planning, imports, issue editing, and cross-version sync.
- Add a self-service OpenCode CLI installer in AI Providers
- Music track editors can now save directly into the full AI Concept → Description → Lyrics → Render workflow.
- Added a System Resources dashboard for storage reports, AI cleanup triage, model memory management, and live job queues

## Changed

- Repo-study issue filing now requires complete area and dispatch labels
- Branch reconciliation now cleans merged worktrees first, limits each coordinator to a configured branch batch, and absorbs the legacy branch-cleanup schedule.
- Music designer drafts now persist immediately and include manual lyrics structure guidance.
- Speed up targeted CI by avoiding duplicate DB loads and narrowing Windows coverage
- Scheduled issue planners now reject speculative future-only refactors while retaining worthwhile current refactors.
- Client lint now checks image alternative text and valid ARIA usage.
- Forms now keep their labels connected to controls as accessibility checks become stricter.
- [4224] Add Apple Silicon MiniMax Music 3 MLX generation with selectable 8-bit and BF16 checkpoints.
- Server unit tests skip the heavy git and sprite integration suites under VITEST_FAST, and those suites share cached git/PNG fixtures so the full run is faster.
- CI caps Vitest at two workers on GitHub Actions and reuses the Vite transform cache between runs.
- Quick POST sessions now offer saved 3, 5, 10, or 15 minute budgets with previews and persisted timing.
- Pinned an LTX-specific Gemma 4 conditioner candidate while keeping it unavailable until the repeated-seed LTX-2.5 behavior gate passes.
- CI skips Windows and a second Vitest pass unless they add signal; tests that only re-ran a copy of the code now exercise the real modules.
- Retired the unused Moltbook/Moltworld class aliases and pinned the services README catalog.
- MiniMax Music 3 now offers a lyric-aware Auto duration mode that leaves room for intro/outro sections, warns when a manual ceiling is too short, and recomputes the recommendation server-side.
- Music now uses the same full-page layout and navigation style as Media Gen.
- Recommend the complete Qwen3.8 27B MLX 4-bit build on Apple Silicon via the LM Studio local-LLM catalog
- Documented changelog:add, fixed stale docs pointers, and collapsed a handful of duplicated helpers.
- MiniMax Music 3 weights download skips the bundled Qwen-7B captioner and the original-format .pth checkpoints its diffusers pipeline never loads — about 29 GB instead of 57 GB
