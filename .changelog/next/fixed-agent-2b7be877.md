- `scripts/setup-image-video.sh` runs its mflux + FLUX.2 preamble again on a bare invocation. The "was any BYOV runtime requested?" check concatenated ten `INSTALL_*` defaults and compared the result to a literal eight-zero string, so it never matched — every bare `bash scripts/setup-image-video.sh` took the BYOV-only branch and silently skipped the image-gen setup it advertises. It now tests for any non-zero character, which cannot drift as runtimes are added.
- Migration 242 no longer suppresses video models added to the catalog after it shipped. Its `_shippedDefaults` bootstrap unioned the user's model ids with **today's** `data.reference/media-models.json`, so on a registry that predated the snapshot key it recorded every current built-in as already-delivered — including entries added long after 242 was written. `appendNewlyShippedEntries` reads a recorded id as "the user deleted this", so those entries were then permanently hidden on exactly the installs that had never seen them, with no later migration able to tell the difference. The bootstrap now unions against the id set pinned in the migration itself.
