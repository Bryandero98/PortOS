# Release v2.47.0

Released: 2026-08-21

## Highlights

- **Federated rendering goes end-to-end.** Image and video jobs can now be discovered, submitted, and run on another instance in your tailnet, with cross-field wire validation, capability gating, and a durable executor that survives a restart. A routed job negotiates its real constraints — frame counts, fps options, canvas dimensions, resolution bounds — against the remote provider instead of guessing, and a downgraded build can no longer silently claim a job it cannot render.
- **Peer capacity is visible before you route to one.** System Health reports media-lane and peer-provider capacity, and the capacity panel refuses to advertise a peer it cannot actually reach. Unattended routing is gated on a tailnet peer, per a new privacy ADR covering federated visual prompts.
- **Image-to-3D got sharper and faster.** TRELLIS.2 stops discarding almost all of its mesh at bake time on Apple Silicon, exposes the full-resolution mesh, and bakes normal maps from the pre-decimation geometry so shading keeps the detail decimation throws away. Per-run render options let you choose a detail tier and transparency instead of having both inferred, background keying removes cast shadows, and Pixal3D joins as a second CUDA target.
- **Chief of Staff runs reconcile against their own ledger.** Run records are cross-checked against the append-only event ledger, so a lost spawn, a late `run.spawned`, a paused run re-adopted by the runner, and a refused TUI handoff all land in the right state instead of drifting. Branch reconciliation reports its real park state rather than "no branches in flight".
- **AI provider setup is legible at a glance.** Provider cards group by readiness, name their local-daemon requirements up front, carry the CLI install call to action, and open a deep-linkable tabbed editor drawer. A stale or path-shaped runtime probe can no longer drop a working provider from routing, and fallback routing skips un-runnable providers instead of ENOENT-ing at spawn.
- **Windows support caught up.** Shell sessions launch in PowerShell, paths join with win32 semantics, tab titles follow a `cd`, injected commands submit with CR, agent TUI commands are quoted for their shell dialect, and the readiness probe is dialect-aware.
- **OpenWorld became a game.** The 3D world is now an isometric rover game with Cyber Shards collectibles, speed boost pads, a speedometer HUD, procedural Web Audio SFX, tightened exploration collisions, and a mobile-playable startup path.
- **Local LLM runtime management.** `llama-server` runs as an optional managed PM2 process with port-collision avoidance, speculative-decoding GGUFs download from the Local LLM card, DSpark joins the evaluated models, and a one-click "Install & start" button drives the local-runtime checklist.
- **Three.js model audits got physical.** Models are checked for pose-aware physical plausibility, non-uniform parent scales, membrane thickness through transformed custom meshes, and whether a declared attachment is actually tied to what it hangs from. PBR materials now get an environment to reflect, with the render profile exported alongside.

## Added

- Federated image and video render discovery, submission, and execution on a selected peer, with a durable executor extracted out of the audio adapter
- Video frame and canvas constraint negotiation over the federated media wire — discrete `frameOptions`, `fpsOptions`, resolution bounds, stride minimums, and canvas tie-breaking (#4681)
- Media-lane and peer-provider capacity reporting on System Health (#4348)
- Unattended render routing to a configured federated peer, gated on a tailnet peer per the federated visual-prompts ADR (#4682)
- Route parameter badges so a routed job shows what it negotiated
- Per-run render options and solid-background keying for image-to-3D (#4657)
- Pixal3D as a second CUDA image-to-3D target (#4677)
- Normal-map baking from the pre-decimation mesh, with per-UV-chart bitangent handedness (opt-in)
- Full-resolution TRELLIS.2 mesh exposed, and kept out of backups
- Pose-aware physical audits for Three.js models (#4543), plus attachment-anchoring checks (#4631) and non-uniform parent-scale detection (#4629)
- Environment reflections for Three.js model PBR materials, with the render profile exported (#4630)
- A forming video render shown on a main stage instead of a bare percentage (#4588)
- Walk-cycle period cross-checked against motion periodicity (#4693)
- OpenWorld as an isometric rover game (#4601, #4605): Cyber Shards collectibles, speed boost pads, speedometer HUD, procedural Web Audio SFX (#4702), landscape polish (#4609), and a mobile-playable path (#4602)
- `llama-server` as an optional managed `portos-llama-server` PM2 process, with port-collision avoidance
- Speculative-decoding GGUF downloads from the Local LLM card, and DSpark evaluated alongside DFlash 2 with llama-server presets
- One-click "Install & start" on the local-runtime checklist
- Local LLM redownload, and Unsloth Dynamic 3.0 Qwen3.8 in the catalog
- CoS run reconciliation against the event ledger, with ledger age-out (#4540)
- App Issues filtering by label, assignee, and blocked status, hiding in-progress work by default
- Stash-cleanup scheduled task type
- Protocol-scoped POST benchmark trends with structured session conditions (#4442)
- A deep-linkable tabbed drawer for the AI provider editor
- Launching a TUI provider straight into a Shell session
- Max effort level for Codex, and a `--issues`/claim-work label skip list (#4645)
- Isolated README demo data seeder

## Changed

- AI provider cards group by readiness, so a missing CLI or API key is visible at a glance; local-daemon requirements are reported on the card instead of failing at run time
- Code Review Defaults moved off the AI Providers page into its own Settings tab; AI run history moved to a Chief of Staff Runs tab
- Contacts moved from Settings to Comms; iMessage ingestion settings moved into a drawer on the iMessage manager page
- Shell sessions launch in PowerShell on Windows, join paths with win32 semantics, follow a `cd` in the tab title (#4624), and submit injected commands with CR
- Agent TUI commands are quoted for their shell dialect (#4642), and the readiness probe is dialect-aware (#4638, #4623)
- A shipped claim worktree is reaped rather than parked for a week, with a shortened shipped-claim window
- The routed-job downgrade contract is enforced inside `enqueueJob` rather than at the call sites (#4683)
- Image pixel primitives are shared across the keying and fingerprinting paths (#4654)
- The environment/render-profile contract moved into a dependency-free module so client CI can import it (#4630)
- CLAUDE.md injection is skipped for Creative Director agent prompts, and dev prompt bloat dropped from the Creative Director CLI (#4650)
- Prompt defaults migrated off the `glab` flags `glab` rejects (#4685)

## Fixed

- A canceled federated render can retry, archived routed jobs normalize on restore, and a corrupt `null` `remoteMedia` marker no longer 500s the retry route (#4683)
- Federation settings merge per sub-key, so Sharing and Instances stop overwriting each other (#4703)
- A lost runner acknowledgement is no longer recorded as a spawn refusal, and a runner 5xx is treated as ambiguous rather than a refusal (#4615)
- A video render child that dies during the accelerator handoff no longer strands the job, and every pre-wiring failure converges on one terminal path (#4617)
- LTX-2 renders retry once when the Metal watchdog aborts the Gemma prompt encoder (#4589); a macOS GPU watchdog kill is classified instead of reported as "generate exited 2"
- MiniMax H3 image-to-video no longer dies in the text encoder before any DiT step, and a moved model pin is reported at Install/Repair rather than on a failed keyframe render (#4606)
- TRELLIS.2 stops discarding 99% of its mesh at bake time on Apple Silicon; `PYTORCH_ENABLE_MPS_FALLBACK` is set before anything imports torch
- RMBG-2.0 is listed as a gated repo for the TRELLIS.2 CUDA lane, and image-to-3D sources are no longer keyed by default so it can remove cast shadows (#4684)
- Contentless packaged sprite frames are rejected at compile time (#4695), and sparse-alpha frames stay degenerate
- Auto-planned music-video cuts snap to the beat grid instead of asserting `beatAligned` (#4664)
- The video continuation anchor is picked by scoring tail frames instead of trusting the end seek (#4666)
- A 3D preview that cannot load a mesh no longer takes the whole page down — it gets its own error boundary, a missing HDRI is survivable, and a model 404 stops being reported as "no WebGL" (#4688)
- Server-owned namespaces return 404 instead of the SPA index (#4688)
- A stale-closure bug that sent mount-time render options instead of the chosen ones
- Provider credential classification is hardened: env-var credentials are detected in readiness, inherited checks are preserved, blank values are clarified, and metadata migrates (#4612)
- A stale or path-shaped runtime probe no longer drops a working provider from routing; fallback routing skips un-runnable providers instead of ENOENT-ing at spawn; a provider resolving its binary outside PortOS's PATH is no longer badged (#4611)
- `llama-server` speculative launch stopped passing a flag llama.cpp has never had; speculative-decoding presets point at Hugging Face repos that exist; llama.cpp installs from the UI no longer report a working binary as missing, and an unlinked brew keg is auto-linked
- PortOS's own PM2 config no longer leaks into apps it launches
- Membrane checks transform custom meshes, account for transformed thickness, keep solid slabs out of the exemption, and support double-sided open shells (#4632)
- Pausing or deleting a creative commission actually stops the work it spawned
- Branch reconciliation reports its real park state instead of "no branches in flight", and a worktree agent is no longer blamed for main's history when the primary sits on an unpushed branch
- The worktree-ownership gate is ordered so a lock structurally outranks a claim (#4668)
- MTPLX starts on a cached checkpoint instead of failing on its default, and surfaces the spawn-error cause when its cache query fails
- The AI Providers editor routes stay on the full-width layout
- The provider card's action buttons no longer starve its details column
- Unpublished releases are reconciled, and a CI failure on the release branch is logged (#4580)
- A malformed peer manifest returns a null failure sentinel rather than an empty result (#4560), an unreadable peer registry is distinguished from a peerless install, and manifest parsers guard individual records with `!Array.isArray`
- OrcaRouter API key setup is discoverable, and the OpenCode OrcaRouter key location is surfaced (#4611)
- Setup probe tracebacks are shown (#4619), BYOV probe stderr is surfaced, and a normal LoRA-probe verdict is no longer reported as a probe failure
- MiniMax Music 3's CUDA offload profile is marked supported (#4359)
- Git-init CD scratch cwd is created and removed on finalize (#4650)
- A queued CoS task shows in the pending list immediately, and only in one place
- The `glab` scan asks for JSON with `--output` rather than the `-F` shorthand that returns a table, and `glabArgs` sorts into the lib barrel correctly
- The duplicate OpenWorld loading screen and duplicate weights-download toast are gone
