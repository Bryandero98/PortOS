# Release v2.46.0

Released: 2026-08-19

## Highlights

- **Local LLM sizing stops being a guess.** PortOS can now *measure* a local model's real resident footprint instead of estimating it from file size, stream that measurement's progress live, flag a reading that has gone stale, and let the measured result overrule the size-estimate fit badge on the catalog card.
- **More model backends.** OrcaRouter joins the provider list (with OpenCode wrappers), an OpenCode llama TUI provider ships alongside surfaced DFlash 2 speculative-decoding support, Antigravity picks up the Gemini 3.7 models, and the curated Qwen3.8 MLX models can be browsed in the Local LLM catalog and imported straight into Ollama. Backends you don't want can be marked disabled and stop nagging from the memory panel.
- **Chief of Staff runs are replayable.** Every CoS run's lifecycle is now recorded in an append-only event ledger you can replay after the fact, completion sentinels are watched (with fallback polling) so a finished agent is noticed promptly, and an active agent card can finish a run or unblock a blocked task directly.
- **Scheduled automations got more control.** A CoS task can be pinned to one federated instance from the web UI, scheduled audits choose between filing issues and implementing the fix, unattended investigations have an explicit approval setting, and review overrides on a scheduled task can be reset.
- **Brain federation is audited at the record level.** The parity check compares actual records rather than just cursor positions, runs on a schedule instead of only when someone presses Check, persists a report per peer, and no longer claims "verified" when a peer served no checksum at all.
- **Creative Director and Music Studio.** Commission briefs can carry a full prompting instruction set rather than a one-line mood, video duration is selectable, render failures queue their own repair tasks, Music Studio can select a remote provider and send finished renders on to audio-to-video, and the effective execution profile used for a music render is recorded and displayed.
- **The video retry editor grew up.** Retries now validate their own configuration, respect the target model's real capabilities, scope their controls correctly, and stop carrying stale chunk prompts, inherited encoders, or unsupported combinations forward.
- **Three.js model specs animate.** Model specs declare animation clips, refinement feedback is derived from those declared clips, and the export ships with a playback helper. CyberCity became OpenWorld — a brighter low-poly world with fast travel between regions.
- **POST training expanded** with a versioned benchmark battery, applied-numeracy drills, executive-control drills, and rhetoric practice.
- **Test suites got faster and safer.** The server vitest configs force `NODE_ENV=test` so a suite run can never aim at the real Postgres, git fixtures are guarded against escaping the temp dir, and the pure client suites now run in a Node environment instead of jsdom.

## Changed

- Release notes are derived from commit history instead of per-branch changelog fragments
- Claim-flow code reviews run locally before the PR opens, and the claim prompts' CI wait is scoped to required checks
- The Shell terminal scrolls by touch, and scrolls at all inside a TUI
- Release checks are database-aware
- Speculative-decoding drafters are never offered as installable models
- Gated local models link out to their Hugging Face terms
- Documentation coverage, feature guides, and JSDoc annotations improved; the DFlash 2 evaluation and the failed LTX conditioner gate are recorded as decision records (#4470, #4510)
- Pure client suites (components, utilities, libraries, service-worker and playback helpers) run in a Node environment rather than jsdom (#4484, #4487, #4489, #4490, #4498–#4501, #4504)
- Post Drill save and Quota Burn debounce suites sped up with explicit React settling and deterministic timers

## Fixed

- Server vitest configs force `NODE_ENV=test`, and git fixtures are guarded against escaping `os.tmpdir()` — closing two temp-path guard holes and a vacuously-passing NODE_ENV guard (#4554)
- Brain parity no longer reports "verified" when the peer served no checksum, and reports persist per peer (#4519)
- Only instances that can actually receive a pinned CoS task are offered, and an orphaned instance pin stays visible and editable (#4520)
- The Git tab's Update button no longer fails on a harmless fetch race
- Release-check "Run Now" no longer sits in awaiting-approve unless Require approval is on (#4547)
- Video retries: validation completed, contracts aligned, control ids scoped, chunk prompts serialized and cleared when a retry drops back to one chunk, inherited encoders cleared on model change, lora capabilities refreshed, unsupported combinations guarded, legacy values preserved, and Grok-only controls hidden
- Video prompt guidance resolves the effective backend and honors the target model, staying backend-neutral for cloud renders
- MiniMax Music 3 lyric sheets are guaranteed a closing section
- Creative-director renders are identifiable in the video queue (#4512)
- Wiki note selection is kept in the URL (#4380, #4507)
- Route errors recover stale chunks and offer a recovery UI (#4525)
- Music video controls are mobile responsive, and the app build loading state is standardized
- A user-disabled local LLM backend is no longer reported as memory-status unavailable, and its memory-panel nag is suppressed without losing the free-everything guard
- The OpenCode installer's postinstall runs despite `ignore-scripts=true`, and synchronous CLI probe spawn failures are handled
- Provider CLI config rejections name the right source, and the OrcaRouter API key is covered in the help text and fallback
- Archived repo-study targets are skipped, studies route to the selected app, and target app labels are used
- CoS agent guidance no longer claims `--review-with` has no effort suffix
