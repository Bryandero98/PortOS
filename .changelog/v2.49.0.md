# Release v2.49.0

Released: 2026-08-24

## Highlights

- Timeline projects can now combine stills, overlays, fades, and an audio bed while keeping preview and export aligned.
- Sprite animation rendering is available across more local runtimes, with queue tracking, restart recovery, packaging progress, and safer retries.
- Video generation gains a capability-aware LTX-2.5 speed profile, chained-render setting preservation, and clearer reference-image promises.
- LoRA workflows can measure whether a LoRA has a real visual effect before a costly render, with bounded probes and honest failure states.
- Quick tasks can plan work through a supported issue tracker, while scheduled feature planning and cloud swarm sizing keep autonomous work inside its configured boundaries.
- Local model servers reclaim idle memory more reliably and use each model's real context window when deciding how to run it.
- Settings, dates, touch targets, themes, and navigation controls are more consistent across devices and configured locales.
- API validation, route pagination, transaction cleanup, and privacy-safe error handling close a broad set of reliability and data-exposure gaps.

## Added

- Layered timeline editing for stills, overlays, fades, and audio beds, including migration support for older timeline data.
- Local MiniMax H3 sprite animation rendering with a Render Queue link for every run.
- A capability-gated LTX-2.5 speed profile with an honest fallback when a render type is unsupported.
- LoRA effect measurement before video rendering, including timeout handling and cached probe results.
- Anchor and Inspire reference-image modes that state the promise made by an image-to-video render.
- Plan-only quick tasks that create work through supported trackers, plus a scheduled task for brainstorming and filing a feature plan.
- Model-server idle-memory release based on actual provider context windows.

## Changed

- Timeline preview and export now share canvas, fade, color, and filename behavior, and older edited clip mirrors remain recoverable.
- Sprite runs survive restarts and attach gaps, file exactly once, report packaging time from packaging start, and let retries re-file the original queue row.
- Settings forms use shared fields, local-date helpers are consolidated, and touch affordances reserve space for pins and navigation banners.
- Chief-of-Staff task planning, federation, cloud claims, and manual swarm counts now honor supported trackers and configured worker limits.
- Local model, video, task-schedule, prompt, socket, database-admin, and synchronization services are split into focused units with shared lifecycle helpers.
- Catalog imports commit transactionally, list routes can opt into pagination, and scheduled writes serialize their record mutations.

## Fixed

- Long DataDog names, search values, blank time ranges, and legacy instance identifiers are preserved through settings and validation.
- External image jobs are cleared on terminal states, model downloads can be canceled, concurrent CivitAI installs are deduplicated, and failed transaction clients are released.
- LoRA probes no longer misreport tiny effects, multi-LoRA or DoRA inputs, external kills, missing files, wedged processes, or stale timeout results.
- Image and video reference controls no longer claim capabilities for unloaded models or treat a legitimate zero strength as unset.
- Filesystem-coded errors and API keys are redacted, route parameters and destructive memory operations are validated, and runtime installs accept only POST requests.
- Calendar, media annotation, MeatSpace, timeline, and catalog writes no longer interleave into lost updates.
- External notification links open correctly, themed SVG and viewport fallbacks survive, and the reviewer controls and responsive navigation keep their intended touch targets.
