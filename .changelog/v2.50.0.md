# Release v2.50.0

Released: 2026-08-25

## Highlights

- Managed applications and scheduled tasks now preserve configured AI provider and model overrides while keeping coding-provider and review behavior consistent.
- Local model workflows gain a refreshed suggested catalog, host-capability filtering, runtime-aware routing, and clearer disconnect and recovery behavior.
- MiniMax H3 LoRAs run through quantized MLX and CUDA-compatible paths with runtime-aware capability checks and updated dependency handling.
- Universe Builder can export readable Markdown world bibles with save-before-export, legacy-shape compatibility, safe prose handling, and bounded export handoffs.
- OpenWorld adds wheel-camera zoom and a richer rover while fixing a mobile frame-loop crash that could leave the scene blank.
- Chief-of-Staff planning and issue claims now decompose eligible epics into independent slices and respect persisted defaults, supported trackers, and explicit claims.
- Navigation, schedule recovery, recurrence, feature participation, and POST surfaces are more resilient across failures, reloads, and configured locales.
- Code organization and accessibility improve through clearer service boundaries, focused module moves, and named form controls.

## Added

- MiniMax H3 LoRA support for quantized MLX and CUDA-oriented runtime paths.
- Markdown world-bible export for universes, including a dedicated download handoff.
- OpenWorld camera zoom and expanded rover presentation controls.
- Creative Director project deletion and per-instance feature participation controls.
- Background POST rhetoric evaluation and product engagement actions.
- Host-capability-aware model selection and a refreshed local LLM suggestion catalog.
- Epic decomposition support for eligible issue-tracker claims and shared friendly recurrence scheduling.

## Changed

- Managed scheduled-task AI overrides now flow consistently through configuration, refresh, execution, and review paths.
- Local model catalogs retain compatibility metadata and provider environments while handling client disconnects without misclassifying provider health.
- Release, issue-claim, and plan-task flows preserve explicit prompts, defaults, and configured reviewer behavior.
- Scheduling consumers share richer calendar recurrence semantics with stable anchors, while the schedules view can recover from failed reads.
- Server modules were reorganized around clearer service and library boundaries, and server tooling dependencies were refreshed.

## Fixed

- Prevented H3 LoRA routing from selecting incompatible runtime layouts or stale capability information.
- Prevented a per-frame mobile easter-egg failure from rendering OpenWorld as a blank sky.
- Made Markdown export wait for current universe writes and preserve safe structure across legacy data shapes.
- Closed POST participation and layout gaps, refreshed disabled feature surfaces, and stabilized hardware-independent route fixtures.
- Added accessible names to previously unnamed select and textarea controls.
