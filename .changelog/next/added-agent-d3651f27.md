- Changelog entries are now written as one small file per branch under `.changelog/next/` instead of being appended to the end of a shared file. Parallel agents each wrote their entry into the same place in `NEXT.md`, so their branches conflicted on merge — routinely stalling every second pull request of a parallel run, and more than once landing conflict markers on main. Two branches writing two different files merge cleanly every time. `npm run changelog:add -- fixed "…"` writes the entry, `npm run changelog:collect` folds them all back into the release notes before a release, and `npm run changelog:preview` reads the assembled unreleased notes without changing anything.
