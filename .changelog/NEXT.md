# Unreleased

## Character LoRA training
- **[issue-2786] Training a character LoRA on an NVIDIA GPU now works.** The torch/diffusers trainer is the path every non-Apple machine takes, but it had only ever been exercised on a 128 GB Mac — where two memory faults did no visible harm, and where the run died at an unrelated Metal limitation before it could reach one of them. On a 24 GB card both were fatal. Preparing the dataset held on to roughly 2.6 GB of scratch memory for every distinct caption it read, so a six-image set exhausted the card before training began; depending on how the driver reacted, that surfaced either as a run that sat at "precompute" for twenty minutes doing nothing visible, or as an out-of-memory abort blaming an allocation far smaller than the space that should have been free. Separately, the preview image the trainer renders at each checkpoint was being decoded on the CPU in a numeric format no CPU has a fast path for, which read as a hang — a single 512-pixel preview took over eighteen minutes. Both are fixed, and a run that previously never finished now trains, checkpoints, previews, resumes from a checkpoint, and produces an adapter that loads cleanly for image generation; a 20-step smoke run completes in about twenty seconds and peaks at 8.8 GB of the card's 24 GB. Apple Silicon behaviour is unchanged — it still refuses up front and points at the mflux runtime, which remains the right choice there.
