## Safety Recommendations

- Do not run this clone on a credentialed desktop until the nonstandard GitShot camera hook is removed or its local provenance is verified. Inspect it manually; do not invoke it.
- Run the app only in a disposable VM or separate OS account with no browser sessions, SSH keys, cloud credentials, or production API tokens.
- Keep `HERMES_GATEWAY_URL` at a verified loopback endpoint unless a remote gateway is intentionally chosen and its TLS/authentication/privacy properties have been reviewed.
- Treat screenshot requests as sensitive: confirm the gateway destination before enabling screen-aware features.
- Install with a fresh virtual environment and inspect resolved packages before first launch; then run `pip-audit` from that isolated environment.
- Restrict outbound network while testing and observe any connection attempts.
