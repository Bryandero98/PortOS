# Release v2.48.0

Released: 2026-08-23

## Highlights

- **Local model serving is managed from the UI, not a terminal.** vLLM and SGLang join llama.cpp, MTPLX, Ollama and LM Studio as first-class local runtimes: a readiness checklist clones, builds and prepares the vLLM Qwen3.8-27B stack for you, SGLang fronts Hopper/Blackwell hardware (including Claude Code providers pointed at its Anthropic-compatible endpoint), MTPLX runs under PM2 with real launch-tuning knobs and UI-managed weights, and every server shares one start/stop control. Temperature, top-p and thinking defaults can be set per local provider.
- **A new Models section, with real measurement behind it.** Media, LoRA, 3D and embedding model management all moved under Models with its own nav home. You can measure any local model across every runtime and see throughput in tokens per second, run an overnight "measure all models" sweep, or sweep one model across a grid of tunings and rank the winner. The Performance page now tests what a model can *do*, not just how fast it is, and Hugging Face download lists show how old each model is.
- **FableLoom — branching narratives.** A new writer for interactive, intent-driven stories: play through a loom, edit it as a graph, and render each scene as an image. Each loom carries a scene format, a narrator pin and a free tapped path; every path gets its own route so two writers can't clobber each other; looms linked to a series surface inside series management.
- **Federated rendering carries real jobs to a peer.** Image Gen and Video Gen can render on another machine in your tailnet, and a job now brings its init image, reference images, video start/end frames and song lyrics along with it. Peers report provider concurrency and per-kind queue occupancy, so the picker shows which machine is actually free, and a queued job's conditioning is pinned against the inbox sweep.
- **Chief of Staff agents respect the hardware they run on.** Concurrent agents are capped per local inference endpoint so one GPU can't be oversubscribed — an explicit "Run now" is never discarded by that cap — and agents recover from a local-GPU out-of-memory stall instead of hanging, with durable feedback about what happened. Per-app provider and model pins are honored on every task type.
- **A stale build is now detectable.** The running build's git commit is stamped into the app and checked on every page, so a server or front-end build that's fallen behind announces itself instead of quietly serving old code.

## Changed

- Concurrent Chief-of-Staff agents are capped per local inference endpoint, keyed by host and port and following a fallback swap; an explicit "Run now" is never discarded by the cap (#4834)
- Per-app provider and model pins are honored on every Chief-of-Staff task type, and the override is shown where the task provider is chosen (#4783)
- Claim tasks remember the reviewers PortOS configured instead of the host's saved defaults (#4770)
- New Chief-of-Staff tasks default to Worktree and Open PR on
- Chief-of-Staff agents recover from a local-GPU out-of-memory stall and surface durable feedback (#4837)
- "Measure this model" and "Sweep tunings" consent gates are routable drawers instead of modals (#4803)
- Scheduled task card headers were redesigned to keep cron timers readable
- Theme contrast tokens, high-opacity control states, calendar, brain-graph, Chief-of-Staff state and forge label colors are graded for the active theme (#4760)
- Subscription usage cards are compact on mobile and show their reset times there
- AI Assignments provider counts are clickable filters
- A published feature list is authoritative for federated media capability gating, and unrecognized features are filtered rather than rejecting the payload (#4826)

## Fixed

- Installed LoRA trigger words are woven into render prompts, so a selected LoRA actually activates (#4665)
- Creative prompts are no longer watered down around named IP
- The Space key no longer opens the voice mic when it should move a character, open a dropdown, or answer a POST drill (#4731)
- A pointer click no longer parks focus on a Space-owning surface's buttons, and a focus trap keeps its aimed initial focus (#4748)
- Local media jobs are refused while a vLLM container is holding the GPU (#4766)
- vLLM-backed providers no longer silently drop their generation controls (#4765)
- A degraded TRELLIS.2 texture bake names the missing module instead of promising an impossible repair (#4636, #4741, #4742)
- Pixal3D's install verify probes its CUDA extensions, so a half-built setup stops reporting success (#4761)
- Embedding-only models are no longer benchmarked on the Performance page, and models that don't say "embed" in their name are still recognized as embeddings
- An MTPLX tuning relaunch launches exactly the tuning asked for, reports failure honestly, and stops as soon as PM2 says the process died
- A held mission task's sub-task is handed back to pending instead of being stranded (#4858)
- A large loom reformat is scoped to one episode per request so it can't time out, and a capped reformat is resumable (#4794)
- A failed PM2 read no longer looks like an externally started llama-server (#4780)
- PortOS's own port no longer leaks into the vLLM compose start (#4821)
- Pinned sidebar rows stay alive when a page moves to a new route
